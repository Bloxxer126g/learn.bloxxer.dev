Setting up your coding enviroment

WinGet

Winget is a command line application provided by Microsoft

It is preinstalled on any Windows PC

Opening the Windows Command Line

We have to use CMD to use winget

! press WIN+R on your keyboard

! type 'CMD' and press enter

Using WinGET to install an application

We now need to use WinGET to search for VSCodium

! winget search vscodium

The top option says 'VSCodium.VSCodium'

Let's install it!

! winget install VSCodium.VSCodium

During the installation, it might ask for admin. Click 'YES'

Using VSCodium

VSCodium is an IDE, it provides a space to work on code.

When you first open VSC it will look something like this:

! Click File -> Open Folder

! Create a new folder in documents (right click, new, folder)

! Name it 'Coding'

You can create a new folder within it for each new project!
