Let's break it down.

Firstly, we have the function, 'print'. This is built in to python.

Next, we have brackets. This tells the computer that you want to run the function.

Finally, we have the text (or string in coding terms). Strings must go in "Quotation marks" or 'apostophies'

Variables

Variables can store data of many different types.

Let's define a variable!

# about-me.py MyName = "Jeff" print(MyName)

We define the 'MyName' Variable, and then call the print function.

# output Jeff

! THINK - Why do we not add "Quotation marks" around MyName in this case?

Awnser: We do not use Quotation marks around MyName, as you only add quotation marks around strings (text). MyName is a variable.

Numeric Values: Integers and Floating Point Numbers

Python, alongside most major coding languages, allows you to store numbers in multiple different forms.

The main two for python are Integers and Floating Point Numbers

(Commonly refered to as Ints and Floats)

Integers

An integer represents any number with no decimal place (called 'floating point' in python)

# about-me.py MyName = "Jeff" MyAge = 21 print(MyName) print(MyAge)

We can now define a MyAge variable, and print() it!

# output Jeff 21

Floats

Floats (Floating Point Numbers) are any number that contain a decimal place. It does not matter what the number after the decimal place is, so both 12.75 and 48.0 are floats.

Simple Greeting program

In this section, we will create a simple app where you can enter your name, and python will say hello.

input()

Another very useful function in python is the input() function

It allows us to ask the user for an input, which must be a string.

How can we use this?
# greeting.py UserName = input("What is your name? ") print("Hello, "+UserName+"!")

# output What is your name? Bob Hello, Bob!

This may look confusing at first, but once you break down the code it makes much more sense.

Firstly, we define a new 'UserName' Variable.

We then set the value of the variable to the result of the input() function

We put 'What is your name? ' in the input function, as that is the question to ask.

Next, we combine our UserName variable, which will be what the user typed, and a greeting message!

The combination of strings is called 'concatination'!

Flowing between datatypes

Sometimes it is neccesary to change the datatype of a value.

In example, let's say we need to ask for the user's age

We want their age as an int, but the input() function returns a string!

To solve this, we need to use the int() function

# See how long until a user turns 100 Age = input("How old are you? ") Age = int(Age) print( str( 100-Age ) + " years until you turn 100")

! THINK - How does this program work?

  1. Asks the user for their age
  2. Converts the Age string to an integer
  3. Works out 100 - Age
  4. Converts that value to a string
  5. Concatinates it with a suffix to make it more readable.

We use int() and str() to flow between datatypes in this example, but we can also use float() and bool() for their datatypes.
