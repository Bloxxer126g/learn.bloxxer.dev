Python files use the '.py' ending, so your PC knows how to open the file.

! Create a new file. Name it 'hello.py'

Our first line

Let's write our first line of python.

All we want to do is make the computer say (print) 'Hello, World!'

# hello.py print("Hello, World!")
Don't worry, print does not send a message to your printer

Try running your program with the play button.

# output Hello, World!

Well done! You just wrote your fist line of python!

Let's break it down.

Firstly, we have the function, 'print'. This is built in to python.

Next, we have brackets. This tells the computer that you want to run the function.

Finally, we have the text (or string in coding terms). Strings must go in "Quotation marks" or 'apostophies'

Variables

Variables can store data of many different types.

Let's define a variable!

# about-me.py MyName = "Jeff" print(MyName)

We define the 'MyName' Variable, and then call the print function.

# output Jeff

! THINK - Why do we not add "Quotation marks" around MyName in this case?

Awnser: We do not use Quotation marks around MyName, as you only add quotation marks around strings (text). MyName is a variable.

Data Types

Strings

Strings are peices of text. They are UTF-8 encoded in python, but that's not important.

We defined a string, MyName in the previous chapter.

Strings are very useful, especially when trying to create a human-useable program.

We always have to wrap strings in "Quotation Marks", so Python knows how to hadle them.
